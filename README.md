# 監査論 穴埋めドリル

公認会計士試験 短答式「監査論」の過去問を、一問一答の2択穴埋め問題に作り直した学習用Webアプリです。
ブラウザだけで動き、インストールやログインは要りません。スマホでも使えます。

アプリはこのリポジトリの GitHub Pages で公開しています。ページ右上の **About** 欄のリンクから開いてください。

## 収録内容

- 令和4年〜令和8年の第Ⅰ回・第Ⅱ回（計10回）の短答式「監査論」
- 各回20問×4肢、**計800問**
- 分野：監査の基礎／監査基準／職業倫理／監査制度／品質管理／監査計画・リスク／監査証拠・手続／不正／監査報告／監査役等との連携／内部統制監査／保証業務・レビュー

## 問題の形式

本試験は「正しい肢の組合せを選ぶ」形式です。このドリルでは、**1つの肢を1問**として出題します。

- 各肢を正しい内容の文に直し、論点となる語句を空欄にしています。
- 選択肢は「正解」と「本試験のひっかけ」の2つです。
- 本試験で誤りだった肢は、正しく直した語句が正解に、本試験の誤った記述がもう一方の選択肢になっています。
- 「該当するものを選ぶ」形式の問題は、原肢の表示が「該当／非該当」になります。

例：

> 過去の経験から経営者が誠実であると認識していても、職業的懐疑心を保持する必要性は〔軽減されない／軽減されることがある〕。

## 主な機能

### ドリル

- 試験回・分野で出題範囲を絞り込めます。
- ランダム出題と過去問の順を選べます。
- 「前回まちがえた問題」や「未回答の問題」だけを出題できます。
- 回答すると、解説と「あわせて確認」が表示されます。「あわせて確認」では、関連する基準、似た制度との違い、結論が変わるケースなどを補足しています。
- 本試験でその肢が正しかったか誤りだったか（原肢 正／誤）も表示します。
- キーボードでは `1`・`2` で選択、`Enter` で次の問題へ進みます。

### 問題一覧

- 試験回・問題番号・解答状況・キーワードで問題を探せます。キーワードは「KAM」「監基報570」のような語句でも検索できます。
- 肢ごとに解説を開いて確認できます。
- 「この問を解く」「この肢を解く」で、特定の問題だけをその場で解けます。
- URLの末尾に `#list` を付けると、問題一覧の画面から開きます。

### 学習記録

- 累計正答率、要復習の問題数、肢ごとの解答状況を記録します。
- 記録は使っているブラウザの中（localStorage）にだけ保存されます。サーバーには送信しません。端末やブラウザが変わると記録は引き継がれません。

## 手元で使う場合

`index.html` をダウンロードして、ブラウザで開けばそのまま使えます。
外部ライブラリは使っていません。フォントだけ Google Fonts から読み込み、オフラインでは端末のフォントで表示します。

## 出典と注意事項

- 問題は、公認会計士・監査審査会が公表している短答式試験「監査論」の問題をもとにしています。本試験の文章そのままではなく、内容を要約・再構成しています。
- 正誤は、同審査会が公表した正解に基づいています。令和4年第Ⅱ回 問16は「正解なし（全員正解）」とされたため、各肢の正誤は作成者の判断です。
- 四半期レビューなど、出題後に制度が変わった論点があります。解説で現行制度に触れていますが、最新の基準・法令で確認してください。
- 解説は学習用の要約です。監査基準、監査基準報告書、公認会計士法、金融商品取引法、会社法などの原文で必ず確認してください。
